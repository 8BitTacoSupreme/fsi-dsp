# LinuxONE CEX / PKCS#11 HSM Guide

Optional hardware security module support using IBM CEX cards for hardware-backed private keys.

## Prerequisites

- IBM CEX card visible to the LPAR (`lszcrypt -V` shows online adapters)
- `opencryptoki` package installed (`dnf install -y opencryptoki opencryptoki-libs`)
- PKCS#11 slot configured and initialized via `pkcsconf`

## CCA vs EP11

IBM CEX cards operate in two modes:

| Mode | Use Case | Provider Library | Key Type |
|------|----------|-----------------|----------|
| CCA | General-purpose crypto, key management | `/usr/lib64/pkcs11/PKCS11_API.so` | CCA keys (non-extractable) |
| EP11 | Enterprise PKCS#11 compliance | `/usr/lib64/pkcs11/PKCS11_API.so` | EP11 keys (HSM-bound, non-extractable) |

EP11 mode keeps private keys inside the CEX HSM. That is a key-storage control, not
Confluent Platform FIPS mode, which is not yet supported on s390x (`docs/linuxone-fips-guide.md`).

## Setup

### 1. Verify CEX Adapters

```bash
lszcrypt -V
# Should show: card0X type CEX[5-8] online
```

### 2. Initialize PKCS#11 Slot

```bash
pkcsconf -t    # List token info
pkcsconf -I    # Initialize token (if new)
pkcsconf -P    # Set user PIN
```

### 3. Generate Key in HSM

```bash
# Generate RSA key pair in PKCS#11 slot
pkcs11-tool --module /usr/lib64/pkcs11/PKCS11_API.so \
  --keypairgen --key-type RSA:2048 \
  --label broker0-key --id 01
```

### 4. Configure Kafka

```properties
# server.properties
ssl.keystore.type=PKCS11
ssl.keystore.location=NONE
ssl.keystore.password=<PKCS11-user-PIN>
# Truststore remains PKCS12 (CA cert doesn't need HSM protection)
ssl.truststore.type=PKCS12
ssl.truststore.location=/etc/kafka/ssl/kafka.truststore.p12
ssl.truststore.password=<truststore-password>
```

### 5. Configure java.security

Add the PKCS#11 provider to `$JAVA_HOME/conf/security/java.security`:

```
security.provider.1=SunPKCS11 /etc/kafka/ssl/pkcs11-provider.cfg
```

The provider config file (`pkcs11-provider.cfg`) is generated by the `cp_mtls` role when `cp_mtls_keystore_backend: pkcs11`.

## Ansible Integration

Enable CEX mode in inventory:

```yaml
# group_vars/all.yml
cp_mtls_keystore_backend: pkcs11
cp_mtls_pkcs11_slot: 0
cp_mtls_pkcs11_cex_mode: EP11  # or CCA
cp_mtls_pkcs11_library: /usr/lib64/pkcs11/PKCS11_API.so
```

## Fallback to Software Keys

If CEX cards are not available or not working, switch back:

```yaml
cp_mtls_keystore_backend: software
```

The `cp_mtls` role will skip all PKCS#11 tasks when backend is `software`.

## Validation

```bash
# Verify PKCS#11 slot is accessible
pkcsconf -t -c 0

# Verify key is in slot
pkcs11-tool --module /usr/lib64/pkcs11/PKCS11_API.so --list-objects

# Verify TLS handshake uses HSM-backed key
KAFKA_OPTS="-Djavax.net.debug=ssl:handshake" kafka-server-start /etc/kafka/server.properties
# Look for PKCS11 in the key manager initialization
```
